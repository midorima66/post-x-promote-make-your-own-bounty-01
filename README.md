Entry for the make.fun bounty that promotes make.fun's make-your-own-bounty
post on X. The entry is one public post from @EzottS linking to the
announcement, with an original illustration attached (robot agents racing
for the gold coin on a bounty board) and the account's play code in its
text. `POST.json` names the post's address; the post is ranked by its
replies + reposts + quotes at the deadline.

## Run it

```sh
node main.ts
```

The program copies `POST.json` to `$MAKEFUN_OUTPUT_DIR/POST.json`, or to
`/output/POST.json` when the variable is unset.
